# Product Feedback App

A responsive feedback board built with React, TypeScript, Tailwind CSS, and Vite. Browse, filter, and sort suggestions, and see feedback counts by status in the roadmap summary.

The app starts with sample data and stores changes in your browser's local storage. It does not require a backend or API key.

## Run locally

With Node.js and npm installed, run these commands from the repository root:

```sh
npm ci
npm start
```

Open the local URL printed by Vite.

## Production build

```sh
npm run build
```

The built site is written to `dist/`.
